# RoboGo 0.2 design

- Date: 2026-10-07
- Status: approved in chat by Czak, including his changes (portable settings and logs, 30-day cleanup).
- Builds on: `2026-10-06-robogo-design.md` (0.1). Everything not mentioned here stays as it is.

## Goal

Six changes asked for after using 0.1: a smaller window, no console flash at start, example texts and a help panel for extra switches, logs shown in the app without leaving files behind, a narrower left column without numbers, and a language button with the plumbing for a later translation.

## Decisions

| Topic | Decision |
|---|---|
| Launcher | `RoboGo.exe`, a small C# program that starts the script with no console. Built by `build.cmd` with the compiler that ships with Windows. Git-ignored. `RoboGo.cmd` stays as a fallback. |
| Portable | The program folder holds everything the app writes: `settings.json` and `logs\`. Nothing goes to `%APPDATA%`. |
| Working log | Robocopy still writes a `/UNILOG` file, because that is the only output with intact file names. It lives in `%TEMP%\RoboGo` and is deleted when the job ends. |
| Kept logs | `Keep log file` (off by default, saved in settings) moves the finished log to `logs\` in the program folder. |
| Cleanup | On launch, `*.log` files older than 30 days are deleted from `%TEMP%\RoboGo` and from `logs\`. This replaces the "newest 20" rule. |
| Language | English texts in one table in the script. `lang\<code>.json` overlays it. `lang\pl.json` ships with every key and English text. The button cycles through the languages found; the choice is saved. |
| Window | Default about 760 x 620 (was 900 x 860), still resizable. Log always visible, short. |

## Portable data

- `$script:RoboAppDir` is the folder of `RoboGo.ps1` (icon).
- `$script:RoboDataDir` is the same folder unless the environment variable `ROBOGO_HOME` names another one. Settings, `logs\` and `lang\` are resolved against it. The tests use `ROBOGO_HOME` so they never touch the real folder.
- `settings.json`: `{ "Language": "en", "KeepLog": false }`. Missing or broken files give the defaults. If the folder is not writable the app keeps working and says so in the status line.

## Texts and language

- `Get-RoboText key [values]` looks in the overlay of the current language, then in the English table, then returns the key itself.
- Every text the app itself produces goes through it: labels, tooltips, placeholders, status lines, problems, warnings, verdicts, dialogs, the help panel.
- Robocopy's own output is shown as robocopy prints it.
- Logic never depends on a text: the preview asks `Test-RoboOptions -SkipEmptyPaths` instead of filtering messages by wording.
- The button in the top right shows the current code (`EN`, `PL`) and switches to the next language on click.

## Window

- Left column 86 px with `PATHS`, `OPTIONS`, `COMMAND`, `PROGRESS`, no numbers, dividers kept.
- The paths hint moves into the FROM tooltip. The mode line is hidden for Copy and shows the red warning for Mirror and Move.
- Example texts appear in FROM, TO, SKIP FILES, SKIP FOLDERS and EXTRA while they are empty.
- `?` next to EXTRA opens a panel:
  - Useful switches, each a check box with one line of explanation. Ticking adds the switch to EXTRA, unticking removes it. The boxes follow what is typed in EXTRA.
  - Recommended setups. Clicking one sets THREADS, Restartable and the switches it names.
- Command row: `Scan first`, `Keep log file`, DRY RUN, RUN, CANCEL.
- Progress column buttons: HIDE LOG, COPY LOG, and OPEN LOG when a kept log exists.
- The log box holds the last 5,000 lines of the job.

## Validation added

`/IPG` in EXTRA with more than 1 thread is refused: robocopy rejects that combination.

## Launcher

- Finds `pwsh.exe` on the PATH, otherwise uses Windows PowerShell.
- Starts it with `-NoLogo -NoProfile -ExecutionPolicy Bypass -STA -File "<folder>\RoboGo.ps1"`, no window, working directory set to the folder.
- A message box reports a missing script or a failed start.
- The window takes `RoboGo.ico` as its icon, so the taskbar shows RoboGo instead of PowerShell.

## Testing

- Core: text lookup and overlay, settings read and write, switch toggling, help data, `/IPG` rule, `pl.json` has exactly the English keys.
- Engine: log deleted or kept at the end of a job, age-based cleanup, every switch in the help panel exists in this Windows's `robocopy /?`.
- Ui: default size, nothing clipped, placeholders, language switch with a throwaway language file, keep-log on and off through real jobs, copy log, help panel toggling, 5,000-line cap.
- Smoke: builds the exe if needed, starts it, watches for any console window during start, runs a dry run and a copy, checks that no log file is left. The same watcher is pointed at `RoboGo.cmd` once to prove it can see a flash.

## Risks

- Defender may distrust a tiny unsigned exe that starts PowerShell hidden. Checked on the desktop during the smoke test. Fallback: a shortcut that starts the hidden host.
- The program folder may be read-only (for example under Program Files). Settings and kept logs then do not persist; the app still runs.
